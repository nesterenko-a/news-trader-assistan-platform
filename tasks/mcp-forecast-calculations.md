# Серверные расчёты для прогнозов MCP

**Этап:** постановка согласована.

## Контекст и цель

При ручной проверке прогноза по SBER (TQBR) в рабочем контуре 12.11.2026 модель показала проценты потенциала и подсчитала рекомендации BUY/HOLD при пустом `calculations`. Производные числа в ответах о прогнозах должны рассчитываться сервером и быть доступны для сверки.

## Границы

Сценарий охватывает потенциал относительно цены из ответа MCP и количество рекомендаций по типам в полученной выборке. Проверка горизонтов, ссылок и истории точности аналитиков остаётся частью [приёмки MCP](./t-invest-mcp.md).

## Критерии готовности

- Если исходных данных достаточно, сервер рассчитывает потенциал относительно цены из ответа MCP и количество рекомендаций каждого типа. Ответ использует значения из `calculations`.
- Если данных для расчёта не хватает, ответ явно сообщает об этом. Числа из ответа брокера отображаются с указанием источника.
- Проверка на подставном ответе MCP покрывает полные и неполные данные.
- Повторный запрос по SBER в рабочем контуре подтверждает, что показанные производные числа совпадают с `calculations`.
