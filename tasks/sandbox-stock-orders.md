# Покупка и продажа акций в Sandbox

**Этап:** спецификация утверждена, реализация подготовлена. Остаётся ручная приёмка на пополненном счёте Sandbox.

Реализация включает форму портфеля, серверную проверку доступного остатка и восстановление статуса заявки по исходному ключу. Для закрытия задачи выполнить ручной сценарий из критериев готовности, сверив портфель через MCP без DeepSeek. [Спецификация](../docs/41-sandbox-stock-orders.md).

## Цель

Добавить ручную покупку и продажу рублёвых акций во вкладке «Портфель» Т‑Инвестиций Sandbox. Пользователь сможет открыть позицию, изменить её размер и сверить новый состав портфеля. Для приёмки аналитики MCP нужна исполненная покупка хотя бы одного лота на тестовом счёте.

## Согласованный сценарий

- «Купить акцию» над списком позиций открывает форму. Поле «Акция» сужает список доступных к покупке бумаг при вводе тикера или названия. Бумагу можно выбрать мышью или с клавиатуры.
- «Изменить» в строке позиции открывает ту же форму для выбранной бумаги с переключателем «Купить / Продать». Форма показывает доступное к продаже количество в лотах и акциях с учётом заблокированного количества.
- Пользователь вводит целое число лотов. До отправки видны выбранный счёт Sandbox, бумага, размер заявки и ориентировочная сумма без комиссии. Кнопка «Купить по рынку» или «Продать по рынку» отправляет заявку сразу из формы.
- После ответа брокера приложение показывает статус заявки. После исполнения обновляются позиция и денежный остаток. При неизвестном статусе пользователь может проверить ту же заявку.

[Согласованный интерактивный макет](../docs/design/sandbox-stock-orders.html), согласован 12.11.2026. Макет показывает поиск бумаги, оба направления операции из строки позиции, доступные к продаже лоты, отправку в один шаг и обновление портфеля на демонстрационных данных.

## Границы MVP

Рыночные заявки на рублёвые акции, ручная отправка с собственного открытого счёта Sandbox и продажа в пределах доступной позиции. Лимитные и стоп-заявки, торговля в рабочем контуре и отправка через LLM или MCP остаются за рамками задачи.

## Критерии готовности

- Поиск фильтрует доступные акции по неполному тикеру или названию. Нельзя отправить заявку с текстом, которому не соответствует выбранная бумага.
- Из строки позиции можно докупить или продать ту же акцию. Продажа сверх доступного количества блокируется сервером.
- Сервер проверяет принадлежность счёта и контур Sandbox. Повторная отправка одной заявки не приводит к повторной сделке. Неизвестный статус проверяется по той же заявке.
- При ручной проверке один лот покупается и появляется в портфеле, затем продаётся. Между операциями количество, доля и денежный остаток сверяются прямым чтением MCP без DeepSeek. После продажи портфель отражает исполнение.
- Покрыты ошибки и повторная отправка, пройдены обязательные проверки проекта и обновлена документация по использованию.
