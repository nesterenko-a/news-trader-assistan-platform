# 14. Веб-интерфейс

**Статус:** утверждено v1.5  
**Система:** NewsTrader Assistant

Описание веб-интерфейса системы. Telegram-бот описан отдельно: [15-telegram-bot.md](./15-telegram-bot.md).

## 1. Общие сведения

- Технология: серверный рендер (Jinja2) + минимальный vanilla JS, без фронтенд-фреймворков.
- Тёмная тема, адаптивная вёрстка.
- Статические файлы: `/static/style.css`, `/static/app.js`.
- По умолчанию доступен по адресу `http://localhost:8000`.

## 2. Маршруты

| Маршрут | Назначение |
|---|---|
| `GET /` | Главная страница: поиск по тикеру, список поддерживаемых бумаг с фильтрами |
| `GET /securities?ticker=AFLT` | Редирект на карточку бумаги (используется поисковой формой) |
| `GET /securities/{ticker}` | Карточка бумаги с аналитикой |
| `GET /securities/{ticker}?range=1y` | Карточка с графиком истории за 1 год |
| `GET /securities/{ticker}?range=5y` | Карточка с графиком за 5 лет |
| `GET /securities/{ticker}?range=all` | Карточка с полной историей (с 2012 года) |
| `GET /login` | Страница входа (форма) |
| `POST /login` | Обработка входа, установка cookie сессии |
| `GET /register` | Страница регистрации (форма) |
| `POST /register` | Создание аккаунта, установка cookie сессии |
| `GET /logout` | Завершение сессии, удаление cookie |
| `GET /watchlist` | Watchlist пользователя (требует входа) |
| `GET /portfolio` | Портфель пользователя с P&L (требует входа) |
| `GET /alerts` | Алерты пользователя и настройки (требует входа) |
| `GET /history` | История стратегий с обратной связью и статистикой качества (требует входа) |
| `GET /macro` | Макрокалендарь: события, регионы, значимость, затронутые бумаги |

## 3. Главная страница

Блоки:
1. **Заголовок и описание** — назначение сервиса.
2. **Поиск** — поле «Тикер» + кнопка «Анализировать»; редирект на карточку бумаги. Неизвестный тикер → 404.
3. **Таблица «Поддерживаемые бумаги»**:
   - столбцы: Тикер, Название, Сектор, Рынок;
   - **фильтры встроены в заголовки столбцов** «Сектор» и «Рынок» (выпадающие списки, авто-применение при выборе, «Все» — сброс);
   - счётчик количества бумаг под фильтром;
   - клик по тикеру открывает карточку бумаги.

## 4. Карточка бумаги

Блоки сверху вниз:

1. **Шапка**: тикер, название, сектор, рынок; справа — вердикт (цветной бейдж) и кнопка «Сделать скриншот».
2. **Параметры стратегии**: горизонт, уверенность, net score.
3. **Котировки**: текущая цена, максимум/минимум дня, объём.
4. **График «История цены»**: серверный SVG-график по сохранённым дневным свечам; переключатель диапазонов **1 год / 5 лет / Всё**; подписи дат и диапазона цен.
5. **Уровни**: Вход, Take-profit, Stop-loss — крупными цифрами (TP зелёный, SL красный).
6. **Обоснование** — краткая выжимка, почему такой вердикт.
7. **Сигналы** — таблица: сущность, тип (прямой/косвенный), тональность, вес, цепочка влияния.
8. **Новости** — лента статей, связанных с бумагой: заголовок-ссылка, источник, дата, упомянутые сущности с тональностью (цветные теги).

**Скриншот:** кнопка «Сделать скриншот» сохраняет всю страницу в PNG. Основной механизм — `html2canvas` (CDN); при его недоступности — встроенный fallback без внешних библиотек (`/static/app.js`).

## 5. Авторизация, Watchlist и Портфель

- **Авторизация:** сессия на cookie `nt_token` (httponly). Незащищённые страницы перенаправляют на `/login`.
- **Навигация:** в шапке — Аналитика, Watchlist, Портфель, API; справа имя пользователя и «Выйти» (или «Войти»).
- **Watchlist (`/watchlist`)**: форма добавления по тикеру, таблица бумаг с последним вердиктом и уверенностью, кнопка удаления.
- **Портфель (`/portfolio`)**: форма добавления позиции (тикер, количество, средняя цена входа), таблица позиций с текущей ценой MOEX, стоимостью, P&L (руб. и %), вердиктом; итоговая строка со стоимостью и P&L всего портфеля. Цвета: зелёный — прибыль, красный — убыток.
- **Алерты (`/alerts`)**: список значимых новостей по бумагам watchlist с метками «новое» и «требует проверки»; кнопки «Прочитано», «Прочитать все»; форма настроек: порог значимости (0–1) и каналы (веб / Telegram); блок **Telegram-уведомления** — привязка чата по коду из бота (`/link`), отображение статуса и кнопка «Отключить Telegram».
- **История стратегий (`/history`)**: таблица сохранённых вердиктов (тикер, вердикт, горизонт, уверенность, дата, версия модели) с кнопками обратной связи **«Сработало / Частично / Не сработало»** (активная оценка подсвечена); вверху — статистика качества пользователя: счётчики и процент сработавших. Аналогичные кнопки доступны на карточке бумаги под вердиктом.
- **Макрокалендарь (`/macro`)**: таблица событий (заседания ЦБ, CPI/PMI/ВВП, сезоны отчётностей) с датой, регионом, значимостью и затронутыми бумагами. **Фильтры встроены в заголовки столбцов**: Регион, Значимость (высокая/средняя/низкая), Бумаги — «Весь рынок» (только рыночные события) / «Бумаги из: Watchlist» / «Бумаги из: Портфель» (только события, привязанные к бумагам из личного кабинета пользователя; рыночные события при этом не включаются). **Сортировка по дате** — клик по заголовку «Дата» переключает порядок (▲/▼). На карточке бумаги — блок «Макрособытия» с ближайшими событиями.

## 6. Запуск

Веб-интерфейс запускается вместе с Telegram-ботом единым лаунчером (`python -m scripts.run_app`, см. [13-operations.md](./13-operations.md)) или отдельно: `uvicorn app.main:app`.
