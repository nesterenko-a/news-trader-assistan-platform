# 14. Веб-интерфейс

**Статус:** утверждено v1.21
**Система:** NewsTrader Assistant

Описание веб-интерфейса системы. Telegram-бот описан отдельно: [15-telegram-bot.md](./15-telegram-bot.md).

## 1. Общие сведения

- Технология: серверный рендер (Jinja2) + минимальный vanilla JS, без фронтенд-фреймворков.
- Тёмная тема, адаптивная вёрстка.
- Статические файлы: `/static/style.css`, `/static/app.js`.
- По умолчанию доступен по адресу `http://localhost:8000`.

## 2. Маршруты

| Маршрут | Назначение |
|---|---|
| `GET /` | Главная страница: поиск по тикеру, список поддерживаемых бумаг с фильтрами |
| `GET /securities?ticker=AFLT` | Редирект на карточку бумаги (используется поисковой формой) |
| `GET /securities/{ticker}` | Карточка бумаги с аналитикой |
| `GET /securities/{ticker}?range=1y` | Карточка с графиком истории за 1 год |
| `GET /securities/{ticker}?range=5y` | Карточка с графиком за 5 лет |
| `GET /securities/{ticker}?range=all` | Карточка с полной историей (с 2012 года) |
| `GET /login` | Страница входа (форма) |
| `POST /login` | Обработка входа, установка cookie сессии |
| `GET /register` | Страница регистрации (форма) |
| `POST /register` | Создание аккаунта, установка cookie сессии |
| `GET /logout` | Завершение сессии, удаление cookie |
| `GET /watchlist` | Watchlist пользователя (требует входа) |
| `GET /portfolio` | Портфель пользователя с P&L (требует входа) |
| `GET /alerts` | Алерты пользователя и настройки (требует входа) |
| `GET /history` | История стратегий с обратной связью и статистикой качества (требует входа) |
| `GET /paper` | Виртуальный портфель (paper trading): счёт, позиции, сделки, метрики и бенчмарк (требует входа) |
| `GET /admin` | Администрирование: запуск основных скриптов и история запусков (только admin) |
| `GET /admin/runs/{id}` | Результат запуска скрипта: статус, код выхода, вывод (только admin) |
| `GET /macro` | Макрокалендарь: события, регионы, значимость, затронутые бумаги |

## 3. Главная страница

Блоки:
1. **Заголовок и описание** — назначение сервиса.
2. **Поиск** — поле «Тикер» + кнопка «Анализировать»; редирект на карточку бумаги. Неизвестный тикер → 404.
3. **Таблица «Поддерживаемые бумаги»**:
   - столбцы: Тикер, Название, Сектор, Рынок;
   - **фильтры встроены в заголовки столбцов** «Сектор» и «Рынок» (выпадающие списки, авто-применение при выборе, «Все» — сброс);
   - счётчик количества бумаг под фильтром;
   - клик по тикеру открывает карточку бумаги.

## 4. Карточка бумаги

Блоки сверху вниз:

1. **Шапка**: тикер, название, сектор, рынок; справа — вердикт (цветной бейдж) и кнопка «Сделать скриншот».
2. **Параметры стратегии**: горизонт, уверенность, net score.
3. **Котировки**: текущая цена, максимум/минимум дня, объём.
4. **График «История цены»**: серверный SVG-график по сохранённым дневным свечам; переключатель диапазонов **1 год / 5 лет / Всё**; подписи дат и диапазона цен.
5. **Уровни**: Вход, Take-profit, Stop-loss — крупными цифрами (TP зелёный, SL красный).
6. **Обоснование** — краткая выжимка, почему такой вердикт.
7. **Контраргументы и риски** — аргументы против вердикта (разнонаправленные сигналы, техсигналы RSI, ближайшие макрособытия) и сгруппированные риски (рыночные, событийные, отраслевые/корпоративные).
8. **Сигналы** — таблица: сущность, тип (прямой/косвенный), тональность, вес, цепочка влияния.
9. **Новости** — лента статей, связанных с бумагой: заголовок-ссылка, источник, дата, упомянутые сущности с тональностью (цветные теги).

**Скриншот:** кнопка «Сделать скриншот» сохраняет всю страницу в PNG. Основной механизм — `html2canvas` (CDN); при его недоступности — встроенный fallback без внешних библиотек (`/static/app.js`).

## 5. Авторизация, Watchlist и Портфель

- **Авторизация:** сессия на cookie `nt_token` (httponly). Незащищённые страницы перенаправляют на `/login`.
- **Значок «Внимание» (!):** отображается в шапке слева от колокольчика алертов (левее троеточия ⋮) у авторизованных и рядом с «Войти» у неавторизованных. По клику открывается попап со списком сообщений. **Четыре состояния значка:** ошибок нет — серый «!» (контур); есть информационные — синий «!»; есть некритичные — янтарный «!»; есть критичные — красный залитый «!» с пульсацией. **Счётчик-бейдж** над значком показывает число активных уведомлений (как у колокольчика, максимум `99+`); цвет бейджа соответствует критичности: синий (info) / янтарный (warning) / красный (critical). Сообщения в попапе выделяются цветом и левой полосой (синие — info, янтарные — warning, красные — critical) с датой; слева от текста — значок проверки по `source` (🗄 БД · 🤖 ИИ · 📡 Telegram · 📈 MOEX · 📰 RSS · 💾 диск · ⏰ устаревание · ⚙️ скрипт). Данные — из `GET /api/notices` (модель `SystemNotice`, см. 07-data-model; ТЗ монитора — [18-health-monitor.md](./18-health-monitor.md)). Уведомления создаются автоматически: сбой скрипта из админки (критично), прерывание запусков перезапуском сервиса (критично), монитором здоровья (БД/LLM/MOEX — критично, Telegram/RSS/диск/устаревание новостей — некритично, долго не запускавшиеся периодические скрипты — информационно).
- **Навигация:** для всех — Аналитика, Календарь, API. **Авторизованному** пользователю в шапке показываются колокольчик алертов и лаконичное вертикальное троеточие (⋮) без кнопочного оформления. Колокольчик расположен слева от троеточия, ведёт на `/alerts` и показывает красный бейдж с числом непрочитанных алертов (максимум `99+`). Троеточие открывает компактный pop-up, выровненный по правому краю, с именем пользователя сверху и пунктами Watchlist, Портфель, Виртуальный портфель, История (и Админ для роли admin), Выйти. Pop-up закрывается по повторному клику, клику вне него или клавише Escape; неавторизованному доступна только ссылка «Войти».
- **Watchlist (`/watchlist`)**: форма добавления по тикеру, таблица бумаг с последним вердиктом и уверенностью, кнопка удаления.
- **Портфель (`/portfolio`)**: форма добавления позиции (тикер, количество, средняя цена входа), таблица позиций с текущей ценой MOEX, стоимостью, P&L (руб. и %), вердиктом; итоговая строка со стоимостью и P&L всего портфеля. Цвета: зелёный — прибыль, красный — убыток. **Закрытие позиции** — кнопка «Закрыть» открывает модальное окно с оценкой исхода: «Сработало / Нейтрально / Не сработало» (или «Отмена»); оценка привязывается к последней стратегии по бумаге и попадает в статистику качества.
- **Алерты (`/alerts`)**: список значимых новостей по бумагам watchlist с метками «новое» и «требует проверки»; кнопки «Прочитано», «Прочитать все»; форма настроек: порог значимости (0–1) и каналы (веб / Telegram); блок **Telegram-уведомления** — привязка чата по коду из бота (`/link`), отображение статуса и кнопка «Отключить Telegram».
- **История стратегий (`/history`)**: таблица сохранённых вердиктов (тикер, вердикт, горизонт, уверенность, дата, версия модели) с кнопками обратной связи **«Сработало / Частично / Не сработало»** (активная оценка подсвечена); вверху — статистика качества пользователя: счётчики и процент сработавших. Аналогичные кнопки доступны на карточке бумаги под вердиктом.
- **Виртуальный портфель (`/paper`)**: имитационная торговля по вердиктам на виртуальный капитал. Счёт (стартовый капитал), таблица открытых позиций с переоценкой по MOEX и P&L (₽ и %), история сделок с привязкой к вердиктам, метрики (доходность, % прибыльных сделок, средний результат, максимальная просадка) и график/сравнение с бенчмарком (IMOEX или «купил всё и держишь»). Кнопка ручного закрытия позиции и сброса портфеля. Позиции открываются/закрываются автоматически в ежедневном конвейере по вердиктам.
- **Администрирование (`/admin`)**: только для роли `admin`. Сетка карточек со скриптами проекта (ежедневный конвейер, сбор новостей, обновление цен, алерты, наполнение календаря/справочников, калибровка, бэктесты) — кнопка «Запустить» (+ числовой параметр там, где нужен); таблица последних запусков со статусом; страница результата с **живым логом**: скрипты запускаются без буферизации вывода и сообщают о ходе работы в реальном времени (фазы конвейера, прогресс по тикерам, «ИИ-анализ» по каждой новости); вывод дозаписывается в БД по мере выполнения, страница авто-обновляется каждые 3 секунды; в конце — статус и код выхода. Одновременно выполняется один скрипт.
- **Макрокалендарь (`/macro`)**: таблица событий (заседания ЦБ, CPI/PMI/ВВП, сезоны отчётностей) с датой, регионом, значимостью и затронутыми бумагами. **Фильтры встроены в заголовки столбцов**: Регион, Значимость (высокая/средняя/низкая), Бумаги — «Весь рынок» (только рыночные события) / «Бумаги из: Watchlist» / «Бумаги из: Портфель» (только события, привязанные к бумагам из личного кабинета пользователя; рыночные события при этом не включаются). **Сортировка по дате** — клик по заголовку «Дата» переключает порядок (▲/▼). На карточке бумаги — блок «Макрособытия» с ближайшими событиями.

## 6. Запуск

Веб-интерфейс запускается вместе с Telegram-ботом единым лаунчером (`python -m scripts.run_app`, см. [13-operations.md](./13-operations.md)) или отдельно: `uvicorn app.main:app`.
