# 14. Пользовательские интерфейсы: веб и Telegram-бот

**Статус:** утверждено v1.0  
**Система:** NewsTrader Assistant

Система доступна через три канала: REST API ([10-api-specification.md](./10-api-specification.md)), веб-интерфейс и Telegram-бот. Этот документ описывает два интерактивных канала.

## 1. Каналы доступа

| Канал | Назначение | Статус |
|---|---|---|
| REST API | Программный доступ, интеграции | ✅ |
| Веб-интерфейс | Аналитика в браузере | ✅ |
| Telegram-бот | Аналитика с телефона в мессенджере | ✅ |

## 2. Веб-интерфейс

### 2.1. Общие сведения

- Технология: серверный рендер (Jinja2) + минимальный vanilla JS, без фронтенд-фреймворков.
- Тёмная тема, адаптивная вёрстка.
- Статические файлы: `/static/style.css`, `/static/app.js`.

### 2.2. Маршруты

| Маршрут | Назначение |
|---|---|
| `GET /` | Главная страница: поиск по тикеру, список поддерживаемых бумаг с фильтрами |
| `GET /securities?ticker=AFLT` | Редирект на карточку бумаги (используется поисковой формой) |
| `GET /securities/{ticker}` | Карточка бумаги с аналитикой |
| `GET /securities/{ticker}?range=1y` | Карточка с графиком истории за 1 год |
| `GET /securities/{ticker}?range=5y` | Карточка с графиком за 5 лет |
| `GET /securities/{ticker}?range=all` | Карточка с полной историей (с 2012 года) |

### 2.3. Главная страница

Блоки:
1. **Заголовок и описание** — назначение сервиса.
2. **Поиск** — поле «Тикер» + кнопка «Анализировать»; редирект на карточку бумаги. Неизвестный тикер → 404.
3. **Таблица «Поддерживаемые бумаги»**:
   - столбцы: Тикер, Название, Сектор, Рынок;
   - **фильтры встроены в заголовки столбцов** «Сектор» и «Рынок» (выпадающие списки, авто-применение при выборе, «Все» — сброс);
   - счётчик количества бумаг под фильтром;
   - клик по тикеру открывает карточку бумаги.

### 2.4. Карточка бумаги

Блоки сверху вниз:

1. **Шапка**: тикер, название, сектор, рынок; справа — вердикт (цветной бейдж) и кнопка «Сделать скриншот».
2. **Параметры стратегии**: горизонт, уверенность, net score.
3. **Котировки**: текущая цена, максимум/минимум дня, объём.
4. **График «История цены»**: серверный SVG-график по сохранённым дневным свечам; переключатель диапазонов **1 год / 5 лет / Всё**; подписи дат и диапазона цен.
5. **Уровни**: Вход, Take-profit, Stop-loss — крупными цифрами (TP зелёный, SL красный).
6. **Обоснование** — краткая выжимка, почему такой вердикт.
7. **Сигналы** — таблица: сущность, тип (прямой/косвенный), тональность, вес, цепочка влияния.
8. **Новости** — лента статей, связанных с бумагой: заголовок-ссылка, источник, дата, упомянутые сущности с тональностью (цветные теги).

**Скриншот:** кнопка «Сделать скриншот» сохраняет всю страницу в PNG. Основной механизм — `html2canvas` (CDN); при его недоступности — встроенный fallback без внешних библиотек (`/static/app.js`).

### 2.5. Запуск

Веб-интерфейс запускается вместе с Telegram-ботом единым лаунчером (`python -m scripts.run_app`, см. [13-operations.md](./13-operations.md)) или отдельно: `uvicorn app.main:app`. По умолчанию: `http://localhost:8000`.

## 3. Telegram-бот

### 3.1. Общие сведения

- Технология: python-telegram-bot (асинхронный, режим polling).
- Логика ответов использует тот же движок стратегий и БД, что и веб/API.
- Хендлеры: `app/bot/handlers.py`; сборка приложения — `app/bot/application.py`.

### 3.2. Команды и поведение

| Команда / сообщение | Поведение |
|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/help` | Справка по командам + дисклеймер |
| Текст с тикером (например, `AFLT`) | Аналитика по бумаге |
| Неизвестный тикер | Сообщение «Бумага не найдена» с подсказкой |

Тикер приводится к верхнему регистру и ищется в справочнике; поддерживаются все бумаги из списка (AFLT, SBER, LKOH, GAZP, NLMK, PLZL, YDEX и др.).

### 3.3. Формат ответа

```
<b>AFLT</b> — Аэрофлот (Авиаперевозки)
Вердикт: <b>SELL</b>
Горизонт: short · Уверенность: 0.61 · Score: -0.421
Вход: 32.98 · TP: 31.33 · SL: 34.63
Обоснование: …
Подробнее: http://localhost:8000/securities/AFLT
```

Используется HTML-разметка (жирный шрифт); ссылка на веб-карточку берётся из `APP_URL`.

### 3.4. Настройка

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота (обязателен для запуска бота) |
| `APP_URL` | Публичный адрес веб-интерфейса для ссылок в ответах бота |

Если `TELEGRAM_BOT_TOKEN` не задан, единый лаунчер запускает только веб-интерфейс.

### 3.5. Запуск

- Вместе с веб-интерфейсом: `python -m scripts.run_app`.
- Только бот (для отладки): `python -m scripts.run_bot`.
- Автозапуск при входе в Windows: ярлык `NewsTraderBot.lnk` в «Автозагрузке» → `scripts/run_app.bat` (без окна консоли).

## 4. Связь с требованиями

| Требование | Реализация |
|---|---|
| FR-10-01 — интерфейс запроса аналитики | Веб-карточка бумаги + бот по тикеру |
| FR-10-02 — карточка бумаги с лентой новостей и индикаторами | Блоки «Сигналы», «Новости», «История цены», котировки |
| FR-10-03 — watchlist и портфель | Запланировано на Этапе 1 |
| UC-01 — запрос аналитики по бумаге | Поиск на главной, карточка, бот |
| UC-02 — лента новостей по бумаге | Блок «Новости» на карточке |
| FR-05-01…FR-05-09 — генерация стратегии и обоснование | Отображаются в карточке и в ответе бота |

## 5. Планы развития интерфейсов

- Экран watchlist и портфеля пользователя (Этап 1).
- Настройки алертов и каналов уведомлений (Этап 1).
- Кнопки-сокращения в боте (например, «похожие бумаги», «лента новостей»).
- Свечные графики (candlestick) вместо линейного.
