# NewsTrader Assistant — Документация

**NewsTrader Assistant** — интеллектуальный ассистент для торговли ценными бумагами, который строит инвестиционные стратегии на основе анализа новостей, статей и их взаимосвязей между отраслями экономики.

Этот набор документов описывает систему целиком — от концепции до API и дорожной карты. Документы рассчитаны на широкую аудиторию: аналитиков, менеджеров, разработчиков и тестировщиков.

Правила ведения документации (единый источник истины, архив реализованных ТЗ, запрет дублирования фактов) — в [32-docs-architecture.md](./32-docs-architecture.md); процесс работы — в [16-working-process.md](./16-working-process.md).

## Краткое описание системы

- **Вход**: пользователь запрашивает аналитику по конкретной ценной бумаге (акции, облигации, ETF и т.д.).
- **Обработка**: система собирает свежие новости и статьи, анализирует их тональность и смысл, учитывает взаимосвязи отраслей экономики (валюты, нефть, ставки, инфляция и пр.).
- **Выход**: стратегия покупки/продажи/удержания с развёрнутым обоснованием — отрывками из статей, ссылками на источники, биржевыми индикаторами и оценкой рисков.
