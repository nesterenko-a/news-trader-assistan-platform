# 21. E2E-тесты веб-интерфейса (Playwright) — ТЗ и план тестирования

**Статус:** утверждено v1.15  
**Система:** NewsTrader Assistant  
**Связанные документы:** [14-web-interface.md](./14-web-interface.md), [16-working-process.md](./16-working-process.md), [13-operations.md](./13-operations.md), [17-quickstart.md](./17-quickstart.md)

## 1. Цель и границы

### 1.1. Цель

Сквозные (end-to-end) браузерные тесты пользовательских сценариев веб-интерфейса через реальный браузер (Playwright, chromium). Тесты проверяют то, что не покрывают unit-тесты и TestClient-смоук (`scripts/smoke.py`): выполнение JavaScript, реальные клики, отправку форм, редиректы, переключение вкладок, мобильное меню, фактический рендер DOM.

### 1.2. Границы

- Тестируется веб-интерфейс (`app/web`) и те вызовы API, которые страницы делают из браузера.
- **Не тестируются:** Telegram-бот, внешние источники (MOEX ISS, DeepSeek LLM, внешние RSS-ленты), фоновые задачи и планировщики.
- Тесты детерминированы и автономны: стенд поднимается глобальным setup'ом с отдельной SQLite-БД, внешние сети не задействуются.
- Набор реализован на **Playwright Test Runner (TypeScript)** и запускается отдельно от unit-тестов: `npx playwright test` (включая **UI-режим** `--ui`); `pytest` остаётся только для unit/интеграционных тестов.

## 3. Архитектура стенда

### 3.1. Расположение

- `tests/e2e/` — тесты TypeScript (`*.spec.ts`) и `playwright.config.ts`;
- `tests/e2e/global-setup.ts` / `tests/e2e/global-teardown.ts` — подъём и остановка стенда;
- `tests/e2e/helpers.ts` — `login()` / `register()`;
- `scripts/e2e_seed.py` — сидинг тестовой БД (Python).

### 3.2. Стенд (globalSetup)

1. Сидинг: `python -m scripts.e2e_seed` создаёт схему и данные в `test-results/e2e.db` (идемпотентно):
   - граф сущностей, влияний и справочник бумаг (SBER, AFLT, LKOH, GAZP и др.);
   - дневные свечи (60 торговых дней) для SBER и AFLT — графики и Volume Profile на карточке;
   - источник `e2e_feed` и статья о Сбербанке (связка через `ArticleEntity` с сущностью «Сбербанк») — блок «Новости» на карточке;
   - 3 макро-события (RU/US, high/medium/low) — фильтры на `/macro`;
   - `Strategy` для SBER (история стратегий);
   - пользователи: `admin` / `admin123` (роль `admin`), `user` / `user123` (роль `user`).
2. Запуск uvicorn-субпроцесса на `127.0.0.1:8765` с окружением `DATABASE_URL=sqlite+aiosqlite:///test-results/e2e.db` и `MOEX_BASE_URL=http://127.0.0.1:9` (внешние сети отключены).
3. Ожидание готовности: poll `GET /v1/health` (fetch) до 200, таймаут ~60 с.
4. PID сервера сохраняется в `test-results/e2e-server.pid`.
5. Teardown: на Windows `taskkill /PID <pid> /T /F` (дерево процессов), на Linux — `SIGTERM`.

### 3.3. Браузер и артефакты

- chromium по умолчанию (проект в `playwright.config.ts`); прогон в другом браузере — `npx playwright test --project=...` / `--browser firefox`;
- при падении — скриншот и trace в `test-results/` (конфиг), отчёт в `playwright-report/` (обе папки в `.gitignore`).

### 3.4. Хелперы (`tests/e2e/helpers.ts`)

- `login(page, username, password)` — переход на `/login`, заполнение формы, ожидание входа;
- `register(page, username, password)` — создание аккаунта;
- константы `ADMIN`/`USER` (admin/admin123, user/user123).

## 5. Команды запуска и регламент

| Действие | Команда |
|---|---|
| Полный прогон (unit) | `.venv\Scripts\python.exe -m pytest -q` |
| E2E-прогон | `npx playwright test` (или лаунчер `scripts\run_e2e.bat`) |
| **UI-режим** (панель со списком тестов, трейсами, перезапуском) | `npx playwright test --ui` |
| Видимый браузер | `npx playwright test --headed` (замедление — `slowMo` в `launchOptions` конфига) |
| Один сценарий | `npx playwright test -g "имя теста"` (или путь к `tests/e2e/*.spec.ts:line`) |
| Отчёт | `npx playwright show-report` (HTML-отчёт из `playwright-report/`) |

Артефакты (скриншот, trace) при падении — в `test-results/<имя теста>/`, отчёт — `playwright-report/` (обе папки в `.gitignore`).

Регламент (по [16-working-process.md](./16-working-process.md) §5):

- Перед каждым коммитом: `compileall` + `pytest -q` (unit).
- E2E — отдельный прогон `npx playwright test`. **Изменение веб-интерфейса (шаблоны, роуты, поведение страниц) обязательно сопровождается актуализацией e2e-тестов:** для новой функциональности тесты добавляются, для изменённой — правятся, для удалённой — удаляются; после любых UI-изменений прогоняется `npx playwright test`.
- **CI (GitHub Actions, `.github/workflows/tests.yml`):** на каждый push в `master` и PR параллельно запускаются unit (`pytest -q`) и e2e (`npx playwright test`, chromium); при падении e2e артефакты `test-results/` выгружаются как `playwright-artifacts`.
- Требование к окружению: Node.js 22 и установленные браузеры Playwright (`npx playwright install chromium`); без них e2e-тесты падают с ошибкой запуска браузера.
- Артефакты e2e (`test-results/`, `playwright-report/`, `node_modules/`) не коммитятся (в `.gitignore`).
