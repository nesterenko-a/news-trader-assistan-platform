# 21. E2E-тесты веб-интерфейса (Playwright) — ТЗ и план тестирования

**Статус:** утверждено v1.2  
**Система:** NewsTrader Assistant  
**Связанные документы:** [14-web-interface.md](./14-web-interface.md), [16-working-process.md](./16-working-process.md), [13-operations.md](./13-operations.md), [17-quickstart.md](./17-quickstart.md)

## 1. Цель и границы

### 1.1. Цель

Сквозные (end-to-end) браузерные тесты пользовательских сценариев веб-интерфейса через реальный браузер (Playwright, chromium). Тесты проверяют то, что не покрывают unit-тесты и TestClient-смоук (`scripts/smoke.py`): выполнение JavaScript, реальные клики, отправку форм, редиректы, переключение вкладок, мобильное меню, фактический рендер DOM.

### 1.2. Границы

- Тестируется веб-интерфейс (`app/web`) и те вызовы API, которые страницы делают из браузера.
- **Не тестируются:** Telegram-бот, внешние источники (MOEX ISS, DeepSeek LLM, внешние RSS-ленты), фоновые задачи и планировщики.
- Тесты детерминированы и автономны: сервер поднимается фикстурой с отдельной SQLite-БД, внешние сети не задействуются.
- Тесты помечаются маркером `e2e` и **исключены из общего прогона** `pytest -q` (`addopts = -m "not e2e"`): sync API Playwright оставляет свой running event loop в основном потоке и конфликтует с pytest-asyncio (см. microsoft/playwright-pytest#167). Запуск — отдельной командой `pytest -m e2e`.

## 3. Архитектура стенда

### 3.1. Расположение

- `tests/e2e/` — директория e2e-тестов. Помечены маркером `e2e`; из общего прогона исключены через `addopts = -m "not e2e"` в `pytest.ini`.
- `tests/e2e/conftest.py` — фикстуры и хелперы.
- `tests/e2e/test_*.py` — сценарии (см. §4).

### 3.2. Фикстура `server` (session-scope)

Автономный тестовый сервер:

1. Свободный порт выбирается через `socket.bind(("127.0.0.1", 0))`.
2. Создаётся временный SQLite-файл (`tmp_path`/`tempfile`) и выполняется сидинг:
   - схема `Base.metadata.create_all` (SQLite, миграции Liquibase не требуются);
   - `seed_graph(session)` — граф сущностей, влияний и справочник бумаг (SBER, AFLT, LKOH, GAZP и др.);
   - `Strategy` для SBER (чтобы была история стратегий);
   - пользователи: `admin` / `admin123` (роль `admin`), `user` / `user123` (роль `user`).
3. Запускается uvicorn-субпроцесс:

   ```
   <sys.executable> -m uvicorn app.main:app --host 127.0.0.1 --port <PORT>
   ```

   с окружением `DATABASE_URL=sqlite+aiosqlite:///<файл>`.
4. Ожидание готовности: poll `GET /v1/health` (httpx) до 200, таймаут ~60 с.
5. Teardown: `terminate()` субпроцесса (при необходимости `kill()`), удаление временного файла БД.

### 3.3. Фикстура `page` и браузер

- `page` — стандартная фикстура `pytest-playwright` (chromium по умолчанию; `--browser firefox` — опционально для P2).
- Скриншоты при падении: запуск с `--screenshot only-on-failure` складывает их в `test-results/` (добавляется в `.gitignore`).

### 3.4. Хелперы (в `conftest.py`)

- `login(page, username, password)` — переход на `/login`, заполнение формы, отправка, ожидание завершения входа (redirect + cookie `nt_token`).
- `register(page, username, password)` — переход на `/register`, создание аккаунта.
- Стандартные учётные данные: `ADMIN_USER/PASSWORD`, `USER_USER/PASSWORD` — константы конфигста.

## 5. Команды запуска и регламент

| Действие | Команда |
|---|---|
| Полный прогон (unit, без e2e) | `.venv\Scripts\python.exe -m pytest -q` |
| Только e2e | `.venv\Scripts\python.exe -m pytest -m e2e` |
| Один сценарий | `.venv\Scripts\python.exe -m pytest -m e2e tests/e2e/test_public.py::test_...` |
| С артефактами при падении | `.venv\Scripts\python.exe -m pytest -m e2e --screenshot only-on-failure` |

Регламент (по [16-working-process.md](./16-working-process.md) §5):

- Перед каждым коммитом: `compileall` + `pytest -q` (unit).
- E2E — отдельный прогон `pytest -m e2e` (быстрее unit-набора не делать обязательным перед каждым коммитом; обязательно при изменении веб-интерфейса).
- Требование к окружению: установленные браузеры Playwright (см. §2); без них e2e-тесты падают с ошибкой запуска браузера.
- Артефакты e2e (`test-results/`) не коммитятся (в `.gitignore`).
