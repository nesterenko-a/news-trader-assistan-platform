# 33. Графики позиций физических и юридических лиц по OI

**Статус:** проект v1.0, ожидает согласования
**Система:** NewsTrader Assistant
**Очередность:** следующая задача к реализации после согласования дизайна.

## 1. Цель и обоснование

На вкладке OI страницы `/indicators` добавить наглядную динамику нетто-позиций физических и юридических лиц по образцу трёх скриншотов пользователя (общий вид и два увеличенных фрагмента одного графика). Пользователь выбирает группу и период, видит преобладание длинных или коротких позиций и изменение относительно предыдущей торговой даты.

## 2. Сценарии и интерфейс

- UC-33-01: открыть OI выбранного фьючерса и блок графика над существующими карточками позиций по датам.
- UC-33-02: переключить «Физические лица / Юридические лица»; график и показатели пересчитываются для выбранной группы. По умолчанию — физические лица.
- UC-33-03: выбрать период «1м / 3м / 6м / 1г / 3г / Всё» или существующий диапазон ОТ/ДО. Периоды отсчитываются от последней доступной даты, чтобы поддерживать архивные контракты; по умолчанию — 1г. Показывать фактический диапазон и число наблюдений.
- UC-33-04: навести на график и увидеть дату, long, short, net и скользящую среднюю; на узком экране показатели переносятся на несколько строк.

Над графиком — карточки «Шорт», «Лонг», «Нетто», «Доля шорта», «Участников», «Перцентиль доли шорта». Значения относятся к последней доступной дате выбранного периода; изменения long/short/net/participants — к предыдущему доступному наблюдению. Число участников отображать только в том смысле, который предоставляет источник; не называть его числом участников в шорте без отдельного поля.

График: фиолетовая линия net, заметная нулевая ось, зелёная заливка между положительным net и нулём, красная — между отрицательным net и нулём; пунктирная золотистая средняя с легендой «Средняя, 30 наблюдений»; последняя точка выделена. Подпись: «Выше нуля — преобладают длинные позиции, ниже — короткие». Ось Y — контракты, X — даты. Карточки записей по датам и существующие графики остаются доступны.

## 3. Требования и расчёты

- FR-33-01: net = long − short; доля шорта = short / (long + short) × 100%. При нулевом знаменателе — «Нет данных».
- FR-33-02: средняя net — арифметическое среднее последних 30 доступных наблюдений включительно с текущим; до накопления 30 точек линия отсутствует. Расчёт предшествует обрезке выбранного периода.
- FR-33-03: перцентиль последней доли шорта — доля валидных наблюдений за предшествующий календарный год включительно с текущей датой, у которых доля шорта не выше текущей. Подсказка раскрывает формулу и фактическое число наблюдений. Для менее двух наблюдений — «Недостаточно данных». Рядом с долей шорта — медиана за то же окно.
- FR-33-04: отсутствующие значения группы не подменять нулями; пропуски показывать разрывом, метрики без данных — прочерком. Пустая история и единственная точка отображаются корректно.
- FR-33-05: показывать дату актуальности и пояснение, что позиции групп агрегированы по базовому активу, а не только по выбранному контракту. Период «Всё» означает доступную сохранённую историю; автоматическое скачивание многолетней истории в этот срез не входит.

## 4. Данные, API и архитектура

Использовать существующие `MarketOpenPositionClientGroup` и `client_groups_series` из `app/market/oi_data.py`: даты и physical/juridical long/short/net/participants. Источник и особенности агрегации — [19-market-indicators.md](./19-market-indicators.md) §8.14; модель — [07-data-model.md](./07-data-model.md).

Новые таблицы и миграции не требуются. При необходимости исправить представление отсутствующей группы в существующем преобразовании данных, не меняя сохранённые записи. Метрики рассчитываются в чистой функции с тестами; веб передаёт графику исторический ряд и показатели. Публичный контракт `/v1/indicators/oi?client_groups=1` сохраняется; новые эндпоинты не требуются. При изменении семантики отсутствующих данных актуализировать API-документацию и контракт.

Использовать существующую библиотеку графиков проекта и общие стили; не подключать новый внешний сервис. Фильтр графика не меняет выбранный инструмент. При переключении индикатора или инструмента корректно освобождать график.

## 5. Приёмка и проверки

Проверить обе группы, все периоды, положительный/отрицательный net и переход через ноль, подсказки, адаптивность, пустые/неполные ряды, среднюю и перцентиль на фиксированных данных. Добавить Python-тесты расчётов и актуализировать Playwright-тесты OI. Выполнить pytest, compileall, smoke и Playwright; при затронутом API — проверки OpenAPI.
