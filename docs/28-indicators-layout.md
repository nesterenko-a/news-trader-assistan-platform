# 28. Редизайн страницы «Индикаторы» — ТЗ и макет

**Статус:** реализовано v1.2 (добавлено автоматическое правое оглавление на широком экране)
**Система:** NewsTrader Assistant  
**Приоритет:** P1, этап 2 дорожной карты  
**Связанные документы:** [12-roadmap.md](./12-roadmap.md), [14-web-interface.md](./14-web-interface.md), [19-market-indicators.md](./19-market-indicators.md), [21-web-e2e-tests.md](./21-web-e2e-tests.md), [26-favorites.md](./26-favorites.md)

## 1. Цель и обоснование

Страница `/indicators` показывает десять реализованных индикаторов. Сейчас они выводятся одной горизонтальной сегментной панелью, где каждая вкладка получает одинаковую ширину. Длинные названия («Профиль объёма», «Поддержка/сопротивление», «Полосы Боллинджера») переносятся на несколько строк, увеличивают высоту отдельных ячеек и визуально ломают границу панели. При добавлении новых индикаторов проблема будет усиливаться.

Цель редизайна — сделать выбор индикатора понятным, устойчивым к длинным названиям и расширяемым без изменения расчётов, URL, API или модели данных.

## 2. Границы

**Входит:** только представление страницы `/indicators`, навигация между уже существующими индикаторами, адаптивный вариант и E2E-покрытие.

**Не входит:** изменение формул, API, URL-параметров, регистрации индикаторов, состава Избранного, данных MOEX, базы данных, прав доступа и содержания результатов.

Текущий URL сохраняется: `/indicators?name={indicator}&ticker={ticker}` с действующими параметрами конкретного индикатора.

## 3. Целевой интерфейс

### 3.1. Desktop и планшет

Страница состоит из двух колонок:

1. **Левый каталог индикаторов** фиксированной читаемой ширины. Это не отдельная карточка и не таблица: вертикальный список с группами.
2. **Рабочая область справа:** заголовок «Индикаторы», краткое описание выбранного индикатора, его форма и результат расчёта.

Каталог показывает группы и элементы:

| Группа | Индикаторы |
|---|---|
| Объём и позиции | Открытый интерес (OI), Профиль объёма |
| Тренд | EMA, MACD, ADX / DI |
| Волатильность и импульс | Полосы Боллинджера, ATR, RSI |
| Уровни и связи | Поддержка / сопротивление, Базис |

Активный индикатор выделяется фоном акцентного цвета. Остальные элементы остаются нейтральными. Полное название выводится в одну строку при доступной ширине; если места всё же недостаточно, текст переносится внутри вертикального пункта, не влияя на соседние пункты или рабочую область.

В рабочей области над формой выводится компактная строка «Выбранный индикатор: …». Она подтверждает контекст после прокрутки и на малом экране становится селектором.

### 3.2. Мобильный экран

При ширине менее 768 px двухколоночный вид отключается:

- каталог заменяется одним нативным селектором с текущим индикатором и всеми группами (`optgroup`);
- после выбора выполняется переход на тот же `/indicators?name=...`, текущие релевантные параметры сохраняются, если это допустимо для выбранного типа;
- форма и результаты занимают всю ширину; поля переносятся в одну колонку или две равные колонки без горизонтальной прокрутки;
- на странице остаётся одна управляющая сущность выбора индикатора: одновременно боковой каталог и селектор не показываются.

### 3.3. Избранное

Редизайн не добавляет отдельный фильтр или сегмент «Избранное» на Индикаторах. Правила [26-favorites.md](./26-favorites.md) сохраняются:

- в поле «Код фьючерса (SECID)» избранные фьючерсы располагаются в начале списка;
- в заголовке построенного результата рядом с тикером остаётся интерактивная звезда;
- звёзды в каталоге индикаторов, Top-5, карте зависимостей, Watchlist и портфелях не добавляются.

## 4. Пользовательские сценарии

### UC-28-01. Открыть индикатор на широком экране

1. Пользователь открывает `/indicators`.
2. Видит вертикальный каталог, сгруппированный по смыслу.
3. Нажимает, например, «Профиль объёма».
4. Открывается существующий маршрут `?name=volume_profile`; форма и расчёт работают без изменения данных.

### UC-28-02. Открыть индикатор на телефоне

1. Пользователь открывает страницу на экране шириной менее 768 px.
2. Видит один селектор текущего индикатора.
3. Выбирает другую группу и индикатор.
4. Страница отображает его форму без горизонтальной прокрутки.

### UC-28-03. Добавить выбранную бумагу в Избранное

1. Авторизованный пользователь строит индикатор по бумаге.
2. Нажимает звезду рядом с тикером в заголовке результата.
3. Отметка меняется без полной перезагрузки; подсказки тикеров обновляются по существующим правилам.

## 6. Технический дизайн

### 6.1. Реестр

Существующий реестр дополняется необязательным полем `category` и, при необходимости, `navigation_order`. Текущие ключи (`oi`, `volume_profile`, `ema`, `macd`, `bollinger`, `atr`, `adx`, `rsi`, `support_resistance`, `basis`) не меняются. Это единственный источник состава каталога и селектора.

### 6.2. Шаблон и стили

- `app/web/router.py` передаёт в шаблон группы каталога, активный ключ и существующие данные результата;
- `app/web/templates/indicators.html` получает семантические `<nav>` для широкого экрана и `<select>` для малого;
- `app/web/static/style.css` отвечает за сетку, перенос и breakpoint 768 px;
- JavaScript не обязателен: ссылки каталога и `onchange` селектора работают как обычные GET-переходы.

### 6.3. Совместимость

- API `/v1/indicators/*`, миграции и БД не меняются;
- ссылка на конкретный индикатор, сохранённая в браузере или документации, продолжает открывать тот же экран;
- текущая звезда Избранного использует существующий API `/v1/favorites`.

## 7. Тестирование и критерии приёмки

Unit:

- маршрутизация и существующие результаты каждого индикатора остаются работоспособными;
- реестр группируется в определённом порядке, неизвестная категория попадает в «Прочие».

E2E:

- на desktop отображается каталог, активен текущий индикатор и переход по каждому пункту открывает нужную форму;
- на viewport 375×667 отсутствует горизонтальная прокрутка, присутствует только селектор, выбор меняет индикатор;
- результаты с тикером сохраняют звезду Избранного и её состояние;
- гость не создаёт запросов к личному API Избранного.

Критерий выхода: нет переполнения или сломанной разметки при всех реализованных индикаторах; `compileall`, `pytest -q`, `npx playwright test` и smoke проходят; документация обновлена.

## 8. Реализация

Реализовано в `app/market/indicators/registry.py`, `app/web/router.py`, `app/web/templates/indicators.html` и `app/web/static/style.css`. Категория хранится в метаданных реестра; неизвестная категория выводится в «Прочие». Широкий экран показывает каталог, на ширине до 760 px остаётся только селектор. Сценарии проверяются в `tests/e2e/public.spec.ts`.
