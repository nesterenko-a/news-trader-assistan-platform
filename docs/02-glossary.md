# 02. Глоссарий терминов

**Статус:** утверждено v1.0  
**Система:** NewsTrader Assistant

Словарь терминов, используемых в документации системы. Обновляется по мере развития проекта.

## Термины системы

| Термин | Определение |
|---|---|
| **NewsTrader Assistant** | Ассистент для торговли ценными бумагами на основе новостного анализа |
| **Пользователь** | Физическое лицо или разработчик, использующий систему через UI или API |
| **Бумага (ценная бумага)** | Торгуемый актив: акция, облигация, ETF, депозитарная расписка |
| **Тикер** | Символьный код бумаги на бирже (например, SBER, AAPL, BTC-USD) |
| **Вердикт** | Итоговая рекомендация: ПОКУПКА / ПРОДАЖА / УДЕРЖАНИЕ |
| **Горизонт** | Период, на который даётся стратегия: кратко-, средне-, долгосрочный |
| **Уверенность** | Степень надёжности вердикта (низкая / средняя / высокая) |
| **Watchlist** | Список отслеживаемых пользователем бумаг |
| **Портфель** | Совокупность бумаг с указанием позиций пользователя |
| **Алерт** | Уведомление пользователя о значимом событии по отслеживаемой бумаге |
| **Обоснование (evidence chain)** | Цепочка «новость → связь → эффект на бумагу», подтверждающая вердикт |
| **Контраргумент** | Аргумент или риск, противоречащий вердикту |
| **Скоринг источника** | Оценка достоверности и репутации источника новостей |

## Аналитика и контент

| Термин | Определение |
|---|---|
| **Новость / статья** | Текст из внешнего источника, прошедший нормализацию |
| **Дедупликация** | Удаление дубликатов и перепечаток одной новости разными источниками |
| **Тональность (sentiment)** | Эмоциональная окраска текста: позитив / негатив / нейтрально |
| **Сущность (entity)** | Объект реального мира: компания, отрасль, сырьё, валюта, индекс, персона, регион |
| **Тематика** | Категория новости: макроэкономика, отрасль, компания, геополитика, регуляторика |
| **Значимость (impact score)** | Оценка силы влияния новости на вовлечённые сущности и рынок |
| **Временное затухание (temporal decay)** | Снижение влияния новости на рынок с течением времени |

## Knowledge graph

| Термин | Определение |
|---|---|
| **Knowledge graph** | Граф знаний: сущности и связи между ними |
| **Узел (node)** | Сущность в графе (компания, отрасль, индикатор) |
| **Ребро (edge)** | Связь между сущностями с параметрами направления и силы |
| **Влияние (impact relation)** | Ребро вида «сущность A → сущность B» со знаком (+/−) и силой |
| **Цепочка влияния** | Путь по графу: событие → промежуточные сущности → целевая бумага |
| **Косвенный эффект** | Влияние, передаваемое через промежуточные сущности |
| **Макроиндикатор** | Экономический показатель: ключевая ставка, CPI, PMI, ВВП, безработица |

## Рынок и биржевые данные

| Термин | Определение |
|---|---|
| **Котировка** | Текущая цена бумаги |
| **RSI** | Индекс относительной силы: перекупленность/перепроданность |
| **MACD** | Схождение/расхождение скользящих средних — индикатор тренда |
| **Скользящая средняя (MA)** | Средняя цена за период; сглаживает волатильность |
| **Уровень поддержки** | Цена, ниже которой бумага исторически не опускается |
| **Уровень сопротивления** | Цена, выше которой бумага исторически не поднимается |
| **Волатильность** | Мера разброса цены; чем выше, тем рискованнее актив |
| **Take-profit / Stop-loss** | Справочные уровни фиксации прибыли и ограничения убытка |
| **Макрокалендарь** | Расписание событий: заседания ЦБ, CPI, PMI, отчётности |
| **Бэктестинг** | Проверка стратегии на исторических данных |
| **Paper trading** | Имитация торговли без реальных денег |

## Экономика

| Термин | Определение |
|---|---|
| **Ключевая ставка** | Ставка центрального банка, влияющая на стоимость денег в экономике |
| **Девальвация** | Снижение курса валюты относительно других валют |
| **Экспортёр** | Компания, продающая продукцию за рубеж; выигрывает от слабой национальной валюты |
| **Импортёр** | Компания, закупающая продукцию за рубежом; проигрывает от слабой национальной валюты |
| **Инфляция** | Рост общего уровня цен; сжигает покупательную способность |
| **CPI (ИПЦ)** | Индекс потребительских цен — мера инфляции |
| **PMI** | Индекс деловой активности в промышленности/услугах |
| **Growth-акции** | Бумаги быстрорастущих компаний; чувствительны к ставкам |
| **Value-акции** | «Стоимостные» бумаги; обычно стабильны и дёшевы относительно показателей |
| **Циклический сектор** | Отрасли, сильно зависящие от фазы экономического цикла (металлургия, стройка) |
| **Оборонка** | Военно-промышленный комплекс; растёт при геополитической напряжённости |

## Технические термины

| Термин | Определение |
|---|---|
| **Конвейер (pipeline)** | Последовательность этапов обработки данных |
| **Коннектор** | Модуль подключения к источнику данных |
| **NLP / LLM** | Обработка естественного языка / большие языковые модели |
| **API** | Программный интерфейс для доступа к функциям системы |
| **Вебхук** | Механизм, при котором источник сам уведомляет систему о новом событии |
| **Хранилище** | База данных или набор хранилищ для данных системы |
