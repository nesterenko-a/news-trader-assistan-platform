## 1. Обоснование (кратко)

Таблица из 11 колонок позиций физ/юр лиц перестала быть читаемой после появления каталога индикаторов. Цель — адаптивный список записей по датам с отдельными блоками физиков и юриков без потери данных.

## 2. Принятое решение

Таблица заменена адаптивными карточками записей по датам: дата, отдельные блоки физических и юридических лиц, сводка и Δ OI. Расчёты, API и источник данных не менялись.
