# 42. Ручные заявки через MCP Т‑Инвестиций в Sandbox

**Статус:** утверждено v1.6 (реализовано, ручная приёмка пройдена, архив).

Ручная приёмка покупки и продажи через общую форму Sandbox подтверждена пользователем. Пробный прямой вызов MCP также исполнил покупку одного лота SBER.

Торговый адаптер использует отдельный список разрешённых операций Sandbox. В каталогах обоих контуров совпали схемы `invest_create_order` и `invest_get_order_state`. Полные хеши закреплены в [адаптере](../../app/brokers/mcp_stock_orders.py). Сервер проверяет владельца, счёт, контур и схему перед вызовом. Аналитическая модель может подготовить черновик, отправку выполняет сервер по действию пользователя.

[Утверждённый макет](../design/mcp-sandbox-orders.html) от 13.11.2026. Действующее поведение описано в [веб-интерфейсе](../14-web-interface.md#покупка-и-продажа-акций-в-sandbox), [контракте API](../10-api-specification.md) и [регламенте эксплуатации](../13-operations.md).

Выбор REST для дальнейших торговых сценариев и статус восстановления заявки по UUID зафиксированы в [дорожной карте](../12-roadmap.md#торговля-и-управление-портфелем-в-тинвестициях).
