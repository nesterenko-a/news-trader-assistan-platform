# 28. Редизайн страницы «Индикаторы» — ТЗ и макет (архив)

**Статус:** архивировано 2026-09-10 (исходный статус: реализовано v1.3). Переведено в архив как ADR-запись по правилам [../32-docs-architecture.md](../32-docs-architecture.md) §4.
**Система:** NewsTrader Assistant

> Это зафиксированная запись о принятом решении (ADR), а не актуальная документация. Актуальные факты живут в базовых документах (см. §3). Полная исходная версия ТЗ — в истории git до коммита архивации.

## 1. Обоснование (кратко)

Горизонтальная сегментная панель из десяти вкладок ломалась на длинных названиях и не масштабировалась под новые индикаторы. Цель — выбор индикатора, устойчивый к длинным названиям и расширяемый без изменения расчётов, URL и API.

## 2. Принятое решение

Навигация `/indicators` строится автоматически из реестра `app/market/indicators/registry.py`: на широком экране — группированный вертикальный каталог по категориям, на узком (≤760 px) — единый нативный селектор; новый индикатор в реестре автоматически получает пункт каталога.
