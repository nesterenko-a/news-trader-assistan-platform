# 34. Подключение Т-Инвестиций только для чтения — решение

**Статус:** архивировано 12.10.2026 (исходный статус: проект v1.1)
**Система:** NewsTrader Assistant

## Обоснование

Пользователю нужен просмотр реального портфеля Т-Инвестиций в NewsTrader Assistant без торговых полномочий. Существующий ручной портфель не содержал данных брокера.

## Решение

Первым брокером подключены Т-Инвестиции с токеном только для чтения. По просьбе пользователя токен хранится зашифрованным в отдельной записи БД, привязанной к его аккаунту; ключ остаётся вне БД. Выбор счёта, обновление и просмотр последнего снимка доступны через веб и API. Торговые заявки и MCP оставлены для последующих задач.
