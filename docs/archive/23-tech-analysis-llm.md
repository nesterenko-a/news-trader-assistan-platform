# 23. Теханализ в LLM — отправка технического анализа бумаги в ChatGPT (архив)

**Статус:** архивировано 2026-09-10 (исходный статус: реализовано v1.11). Переведено в архив как ADR-запись по правилам [../32-docs-architecture.md](../32-docs-architecture.md) §4.
**Система:** NewsTrader Assistant

> Это зафиксированная запись о принятом решении (ADR), а не актуальная документация. Актуальные факты живут в базовых документах (см. §3). Полная исходная версия ТЗ — в истории git до коммита архивации.

## 1. Обоснование (кратко)

Пользователю на карточке бумаги нужен внешний независимый технический разбор от LLM на основе всех накопленных системой данных (цена, объём, уровни, Volume Profile, RSI, для фьючерсов — OI, клиентские позиции, базис), чтобы ускорить торговое решение. Не-цель: не замена движку стратегий.

## 2. Принятое решение

Кнопка «Теханализ в LLM» на карточке акций/фьючерсов: актуализация данных → формирование запроса (промпт `docs/promt_tech_analize.md`) → отправка в LLM; записи `TechAnalysis` со статусами и этапами; карточки результатов (вердикт/вход/TP/SL) и страница полного ответа `/tech_analysis/{id}` со сценариями A/B/C.
