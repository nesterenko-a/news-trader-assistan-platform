## 1. Обоснование (кратко)

Одиночный Теханализ работает по одной бумаге; для группы акций («зерновые», «металлургия») приходилось запускать разбор по каждой и вручную сравнивать. Цель — автоматически выбрать лучшие сделки шаблона: рейтинг по Expected R = prob×RR − (1−prob)×1.

## 2. Принятое решение

Страница `/top5`: батч теханализа по акциям шаблона `kind=stock` (модель `TechAnalysisBatch`), рейтинг Top-5 по Expected R с раскрытием сценариев A/B/C и «Итоговой оценкой»; «Шаблоны фьючерсов» рефакторены в «Шаблоны инструментов» с полем `kind` (миграция 027).
