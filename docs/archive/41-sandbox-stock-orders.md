# 41. Рыночные заявки на акции в Sandbox

**Статус:** архив, v1.2. Реализация принята.

Рыночные заявки нужны для ручной проверки изменения портфеля. Пользователь выставляет заявку на рублёвую акцию со своего открытого счёта Sandbox. Исходный ключ заявки защищает от повторной отправки и позволяет проверить статус после сбоя.

В рабочем сценарии пользователь купил и продал один лот MGNT. Прямое чтение MCP подтвердило изменения позиции и рублёвого остатка. [Результат приёмки](../12-roadmap.md#рыночные-заявки-на-акции-в-sandbox).
