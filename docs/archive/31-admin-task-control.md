# 31. Управление фоновыми задачами администратором (архив)

**Статус:** архивировано 2026-09-10 (исходный статус: утверждено v1.6). Переведено в архив как ADR-запись по правилам [../32-docs-architecture.md](../32-docs-architecture.md) §4.
**Система:** NewsTrader Assistant

> Это зафиксированная запись о принятом решении (ADR), а не актуальная документация. Актуальные факты живут в базовых документах (см. §3). Полная исходная версия ТЗ — в истории git до коммита архивации.

## 1. Обоснование (кратко)

Полное управление фоновыми задачами, включая realtime-демон, сосредоточено в `/admin`: запуск скриптов, параметры, журнал, остановка активного запуска. В шапке элементов управления нет.

## 2. Принятое решение

Карточки задач в `/admin` с switch «OFF / Запустить» и «ON / Остановить» без диалога подтверждения; остановка — `POST /admin/scripts/{run_id}/stop` (terminate → kill через 10 с), аудит в `ScriptRun` (`stopped_by`/`stopped_at`); в `/settings` у администратора — только якорный раздел «Администрирование» с активными задачами и toggle остановки.
