# 30. Автоматические кандидаты связей графа и кураторское подтверждение (архив)

**Статус:** архивировано 2026-09-10 (исходный статус: реализовано v1.0). Переведено в архив как ADR-запись по правилам [../32-docs-architecture.md](../32-docs-architecture.md) §4.
**Система:** NewsTrader Assistant

> Это зафиксированная запись о принятом решении (ADR), а не актуальная документация. Актуальные факты живут в базовых документах (см. §3). Полная исходная версия ТЗ — в истории git до коммита архивации.

## 1. Обоснование (кратко)

Система должна находить в уже проанализированных новостях возможные новые связи «сущность → сущность» и передавать их куратору. Цель — расширять knowledge graph доказуемо, без автоматического внесения недостоверных рёбер в стратегии. Первая версия — только новые связи между существующими сущностями.

## 2. Принятое решение

Очередь кандидатов: извлечение evidence из новостей, агрегация (strength — большинством предложений), admin API и страница `/admin/graph/candidates` (вкладки, правки полей, approve/reject/need-evidence). До принятия кандидат не влияет на карту зависимостей и стратегии.
