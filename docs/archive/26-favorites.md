# 26. Избранные ценные бумаги — ТЗ и дизайн (архив)

**Статус:** архивировано 2026-09-10 (исходный статус: реализовано v1.4). Переведено в архив как ADR-запись по правилам [../32-docs-architecture.md](../32-docs-architecture.md) §4.
**Система:** NewsTrader Assistant

> Это зафиксированная запись о принятом решении (ADR), а не актуальная документация. Актуальные факты живут в базовых документах (см. §3). Полная исходная версия ТЗ — в истории git до коммита архивации.

## 1. Обоснование (кратко)

Пользователю нужно помечать акции и фьючерсы избранными, чтобы быстро находить их при анализе и вводе тикера. Избранное — личный список, не равен Watchlist (не порождает алерты).

## 2. Принятое решение

Таблица `user_favorites` (миграция 030), API `/v1/favorites`, звезда на Аналитике, в шапке карточки бумаги и в заголовках результатов Индикаторов; фильтр «Избранное» на Аналитике, раздел в Настройках, приоритет избранного в подсказках тикера.
