**Связанные документы:** [03-user-scenarios.md](./03-user-scenarios.md), [04-functional-requirements.md](./04-functional-requirements.md), [07-data-model.md](./07-data-model.md), [10-api-specification.md](./10-api-specification.md), [12-roadmap.md](./12-roadmap.md), [14-web-interface.md](./14-web-interface.md), [16-working-process.md](./16-working-process.md)

## 1. Цель и границы

Пользователь помечает акции и фьючерсы как **избранные**, чтобы быстро находить их при анализе и вводе тикера. Избранное — личный список: состав не виден другим пользователям.

Избранное **не равно Watchlist**. Watchlist остаётся списком для алертов, мониторинга новостей и состава realtime-демона. Добавление в Избранное не создаёт алерт, не меняет watchlist и не увеличивает запросы к MOEX.

Входят: добавление/снятие отметки непосредственно звездой рядом с тикером, отдельная страница личного списка в настройках пользователя, фильтр «Избранное» на Аналитике и Индикаторах, избранные первыми в подсказках. Не входят: папки, ручная сортировка, экспорт, синхронизация с брокером и влияние на алерты/realtime.

## 2. Пользовательские сценарии

### UC-26-01. Добавить бумагу

Авторизованный пользователь нажимает контурную звезду непосредственно рядом с тикером акции или фьючерса. Связь сохраняется без перезагрузки, звезда становится заполненной, а тикер сразу попадает в фильтр и начало подсказок.

### UC-26-02. Убрать бумагу

Пользователь нажимает заполненную звезду. Удаляется только его отметка, а звезда возвращается в контурное состояние.

### UC-26-03. Анализировать избранное

На `/` пользователь выбирает **«Избранное»** среди «Акции / Фьючерсы / Избранное / Все». Система показывает только его бумаги и сохраняет фильтры сектора и рынка. При пустом списке выводится «Избранных бумаг пока нет» и ссылка на «Все».

### UC-26-04. Выбрать любимый тикер в Индикаторах

На `/indicators` пользователь выбирает сегмент «Избранное». Подсказки тикера содержат только избранные бумаги; на вкладке OI — только избранные фьючерсы.

### UC-26-05. Открыть личный список Избранного

1. Пользователь открывает меню по кнопке «⋮» в шапке.
2. Нажимает на свой никнейм, который является ссылкой «Настройки пользователя».
3. На странице `/settings` открывает раздел «Избранное» и видит все личные избранные бумаги.
4. Переходит к бумаге по тикеру или снимает отметку звездой рядом с тикером.

### UC-26-06. Быстрый ввод тикера

При фокусе на любом общем поле тикера сначала предлагаются избранные подходящего типа, затем остальные бумаги. Если посетитель не авторизован, личный список и звёзды не показываются.

## 4. Модель данных

Новая таблица `user_favorites`:

| Поле | Тип | Назначение |
|---|---|---|
| `id` | INTEGER PK | Идентификатор |
| `user_id` | INTEGER FK → `users.id`, NOT NULL | Владелец |
| `security_id` | INTEGER FK → `securities.id`, NOT NULL | Избранная бумага |
| `created_at` | TIMESTAMP WITH TIME ZONE, NOT NULL | Время добавления |

Ограничения: `UNIQUE(user_id, security_id)` и индекс `(user_id, created_at DESC)`. В реализации добавляются модель `UserFavorite` и Liquibase `029_user_favorites.xml`. Связь с Watchlist независима: одна бумага может быть в обоих списках или только в одном.

## 5. API

Все методы требуют `nt_token`/Bearer и всегда работают только с текущим пользователем.

| Метод | Путь | Назначение | Ответ |
|---|---|---|---|
| `GET` | `/v1/favorites` | Личный список с данными бумаги | `{"items":[{"ticker","name","security_type","sector","market","created_at"}]}` |
| `PUT` | `/v1/favorites/{ticker}` | Добавить бумагу; повтор безопасен | `{"ticker":"SBER","is_favorite":true}` |
| `DELETE` | `/v1/favorites/{ticker}` | Убрать бумагу; отсутствующая отметка не ошибка | `{"ticker":"SBER","is_favorite":false}` |

Ошибки: `401` — гость, `404` — тикер не найден, `400` — неподдерживаемый тип. Звезда вызывает API через `fetch()` и не перезагружает страницу.

## 6. Интерфейс

### 6.1. Компонент звезды

`favorite-toggle` — кнопка с inline-SVG пятиконечной звездой, не Unicode-символ: это обеспечивает одинаковый результат в браузерах.

- не добавлена: прозрачная заливка, жёлтый контур `#f0b429`;
- добавлена: заливка и контур `#f0b429`;
- 20×20 px в заголовках, 16×16 px в строках;
- доступны наведение и клавиатурный фокус; на время запроса кнопка блокируется, при ошибке состояние возвращается.

Кнопка не вкладывается в ссылку тикера. Она есть только у авторизованного пользователя.

### 6.2. Места вывода

| Экран | Расположение |
|---|---|
| `/` Аналитика | Перед тикером в таблице бумаг |
| `/securities/{ticker}` | В шапке рядом с тикером |
| `/indicators` | В заголовке результата выбранной бумаги; для OI — рядом с SECID |
| `/map` | В заголовке выбранной бумаги |
| `/top5` | Перед тикером в строках результатов |
| Watchlist, портфель, виртуальный портфель | Рядом с тикером, если он ведёт на карточку бумаги |

Звезда всегда находится рядом с текстом тикера, а не в отдельной колонке действий или в карточке без тикера. Установка и снятие отметки выполняются именно этой кнопкой.

### 6.3. Настройки пользователя и личный список

В меню пользователя по кнопке «⋮» имя пользователя становится кликабельной строкой. Клик открывает новую приватную страницу `/settings` с заголовком «Настройки пользователя».

Первый раздел страницы — **«Избранное»**:

- таблица: звезда, тикер, название, тип, сектор, рынок, дата добавления;
- тикер ведёт на `/securities/{ticker}`;
- звезда находится рядом с тикером и снимает отметку без перезагрузки;
- при пустом списке: «Избранных бумаг пока нет» и ссылка на Аналитику;
- страница не заменяет текущие Watchlist, Портфель и настройки алертов — это самостоятельный личный список.

### 6.4. Фильтры и подсказки

На Аналитике сегменты: **Акции / Фьючерсы / Избранное / Все**. На Индикаторах: **Все / Акции / Фьючерсы / Избранное**; он управляет набором тикеров, не меняя вкладку индикатора. В меню пользователя остаётся ссылка на Watchlist, а клик по никнейму открывает личное Избранное в настройках.

Общий JS-загрузчик получает `/v1/securities` и `/v1/favorites`, объединяет списки без дублей и строит datalist в порядке: избранные подходящего типа по тикеру, затем остальные. После нажатия звезды кэш текущей страницы обновляется сразу.

## 7. Потоки и безопасность

```text
Нажатие звезды → PUT/DELETE /v1/favorites/{ticker}
→ проверка сессии и Security → insert/delete user_favorites
→ JSON is_favorite → обновление звезды и кэша подсказок
```

```text
GET /?type=favorites → текущий пользователь
→ Security JOIN user_favorites по user_id → sector/market → таблица или пустое состояние
```

`user_id` берётся только из сессии. Пользователь не может читать или менять чужой список. Избранное загружается один раз на страницу и кэшируется браузером.

## 8. Тестирование и критерии приёмки

Unit: добавление/повторное добавление/удаление, изоляция двух пользователей, API 401/404, фильтр Аналитики, порядок подсказок и типовые ограничения.

E2E: добавление акции и фьючерса со сменой звезды после перезагрузки; удаление; фильтры на Аналитике и Индикаторах; OI не предлагает акции; избранный стоит первым; другой пользователь не видит отметку; гость не видит личный фильтр и получает 401 от API.

Дополнительно: клик по никнейму в меню «⋮» открывает `/settings`; страница показывает только личное Избранное; снятие звезды в настройках обновляет строку без перезагрузки.

Критерий выхода: выполнены FR-26, пройдены `compileall`, `pytest -q`, `npx playwright test`, smoke; обновлены docs 04/06/07/10/12/14/17.

## 9. Решение для согласования

Предлагается делать Избранное независимым от Watchlist и **не** добавлять бумаги в Watchlist автоматически. Это исключает неожиданные алерты и дополнительную нагрузку realtime-демона. Автодобавление в Watchlist, если оно понадобится, должно быть отдельным явно согласованным правилом.
