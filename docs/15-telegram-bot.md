# 15. Telegram-бот

**Статус:** утверждено v1.3  
**Система:** NewsTrader Assistant

Описание Telegram-бота как канала доступа. Веб-интерфейс описан отдельно: [14-web-interface.md](./14-web-interface.md).

## 1. Общие сведения

- Технология: python-telegram-bot (асинхронный, режим polling).
- Логика ответов использует тот же движок стратегий и БД, что и веб/API.
- Хендлеры: `app/bot/handlers.py`; сборка приложения — `app/bot/application.py`.

## 2. Команды и меню

В чате с ботом доступна **кнопка меню** (иконка меню у поля ввода): по нажатию показывается кликабельный список команд, настроенных через `setMyCommands`.

| Команда | Описание в меню | Поведение |
|---|---|---|
| `/start` | Приветствие и инструкция | Приветствие и краткая инструкция |
| `/link` | Привязать аккаунт для алертов | Выдаёт одноразовый код для привязки Telegram к аккаунту сайта (см. раздел 3.2) |
| `/help` | Справка по командам | Справка по командам + дисклеймер |

Помимо меню, бот обрабатывает обычные текстовые сообщения:
- **тикер** (например, `AFLT`) — аналитика по бумаге;
- **неизвестный тикер** — сообщение «Бумага не найдена» с подсказкой.

Тикер приводится к верхнему регистру и ищется в справочнике; поддерживаются все бумаги из списка (AFLT, SBER, LKOH, GAZP, NLMK, PLZL, YDEX и др.).

## 3. Формат ответа

Сообщение структурно повторяет карточку бумаги веб-интерфейса:

```
<b>AFLT — Аэрофлот</b>
<i>Сектор: Авиаперевозки · Рынок: MOEX</i>

<b>Вердикт: SELL</b>
Горизонт: short · Уверенность: 0.61 · Net score: -0.416
Вход: 32.88 · Take-profit: 31.24 · Stop-loss: 34.52

Обоснование: нефть: усиливает (-0.25); …

Сигналы:
• [косвенный] Нефть (positive): -0.247
• [прямой] Компания (negative): -0.460

Новости:
• <a href="https://tass.ru/…">Заголовок статьи</a> — ТАСС, 31.07.2026 12:45
• <a href="https://www.interfax.ru/…">Заголовок статьи</a> — Интерфакс, 31.07.2026 12:45

Подробнее: <a href="http://localhost:8000/securities/AFLT">AFLT — аналитика</a>
```

Используется HTML-разметка, поддерживаемая Telegram (`<b>`, `<i>`, `<a href>`); значения экранируются. Ссылка на веб-карточку берётся из `APP_URL`. Блок «Новости» (до 5 статей) со ссылками на источники повторяет ленту новостей веб-интерфейса.

## 3.1. Общая логика отображения (фабрика)

Текст и веб-карточка строятся из одной общей модели данных — слоя представления `app/presentation`:

- `view.py` — `build_strategy_view(...)`: фабрика, которая нормализует результат движка в структуру `StrategyView` (шапка, вердикт, параметры, уровни, обоснование, сигналы, новости).
- `factories.py` — две фабрики-рендерера:
  - `TelegramMessageFactory` — собирает HTML-сообщение для Telegram;
  - `WebContextFactory` — готовит контекст для шаблона веб-интерфейса.
- Новости загружаются общим сервисом `app/news/service.py` (список статей с сущностями и тональностью) — используется и вебом, и ботом.

Благодаря этому логика подготовки данных не дублируется между каналами: движок → `StrategyView` → рендер в нужный формат.

## 3.2. Push-алерты в Telegram

Пользователь может получать уведомления о новых алертах в Telegram.

**Привязка чата к аккаунту:**
1. В боте: команда `/link` → бот выдаёт одноразовый код (6 символов, действует 15 минут).
2. В веб-интерфейсе: страница `/alerts` (или API `POST /alerts/telegram/link`) → вводится код, чат привязывается к аккаунту.
3. В настройках алертов включается канал **Telegram**.

**Доставка:** при генерации алертов (`daily_pipeline`, `scripts/process_alerts.py`) для пользователей с включённым каналом `telegram` и привязанным чатом отправляется сообщение:

```
<b>Новый алерт по SBER</b>
Значимость: 0.90

<a href="https://…">Заголовок новости</a>
Подробнее: <a href="http://localhost:8000/securities/SBER">SBER — аналитика</a>
```

Текст формируется общей фабрикой `app/presentation/factories.py:build_alert_message`. Отправка — `app/bot/push.py`. Если `TELEGRAM_BOT_TOKEN` не задан, доставка молча пропускается.

## 4. Настройка

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота (обязателен для запуска бота) |
| `APP_URL` | Публичный адрес веб-интерфейса для ссылок в ответах бота |

Если `TELEGRAM_BOT_TOKEN` не задан, единый лаунчер запускает только веб-интерфейс.

Меню команд задаётся при старте: в едином лаунчере — явно (`apply_menu`), при запуске только бота — через `post_init`.

## 5. Запуск

- Вместе с веб-интерфейсом: `python -m scripts.run_app`.
- Только бот (для отладки): `python -m scripts.run_bot`.
- Автозапуск при входе в Windows: ярлык `NewsTraderBot.lnk` в «Автозагрузке» → `scripts/run_app.bat` (без окна консоли).

## 6. Связь с требованиями

| Требование | Реализация |
|---|---|
| FR-10-01 — интерфейс запроса аналитики | Запрос тикера сообщением |
| FR-05-01…FR-05-09 — генерация стратегии и обоснование | Ответ бота с вердиктом и обоснованием |
| UC-01 — запрос аналитики по бумаге | Команда `/start`, текст с тикером |
